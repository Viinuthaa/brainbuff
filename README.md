# BrainBuff

BrainBuff is a responsive e-learning landing page designed to showcase online courses, learning features, pricing plans, and student testimonials.

## Features

- Hero section with calls to action and statistics
- Featured courses for web development, Python, and AI
- Learning features and step-by-step process
- Student testimonials and pricing plans
- FAQ section and contact form
- Navigation bar and footer

## Tech Stack

- HTML5
- CSS3
